# 为什么 85% 混合 > 100%（teacher 内容）：写完率 × 写对率 的分解（2026-10-12，零 GPU，后 300 题）

student = M(.4,.6)，teacher = A(2.0)。剂量 = 两模型分歧位置里交给 teacher 的比例。写完 = 文本含 `\boxed`；未写完的题全部为错（0.0%）。

| 系统 | acc | 写完率 | 写完的题里 acc | 平均长度（字符） |
|---|---:|---:|---:|---:|
| **剂量曲线（student M(.4,.6)，teacher A(2.0)）** | | | | |
| M(.4,.6) 单独（0%） | 42.0 | 81% | 51.9 | 1123 |
| 随机 26% | 46.3 | 84% | 54.9 | 1463 |
| 门控 @0.4（26%） | 43.7 | 83% | 52.6 | 1319 |
| 门控 @0.6（58%） | 49.7 | 89% | 56.0 | 1474 |
| 随机 85% | 50.0 | 93% | 53.6 | 2678 |
| **门控 @0.8（85%）** | 51.0 | 89% | 57.3 | 1893 |
| @1.0（100%，teacher 内容 + student 顺序） | 46.3 | 95% | 48.8 | 2816 |
| A(2.0) 单独 | 46.7 | 94% | 49.5 | 2824 |
| **控制变量** | | | | |
| 换 teacher 剂量：A(3.0) 单独 | 34.0 | 72% | 47.0 | 3126 |
| 换 teacher 剂量：M(.4,.6) ⇐ A(3.0) @0.8 | 42.3 | 77% | 54.7 | 2525 |
| 权重中点替身：(0.7,1.3) 单独（1×） | 44.3 | 89% | 49.8 | 3296 |
| 换 student：Ins 单独 | 36.7 | 76% | 48.5 | 918 |
| 换 student：Ins ⇐ A(2.0) @0.8 | 49.0 | 93% | 52.9 | 2133 |
| 换 teacher 线：M(0,1) 单独 | 44.0 | 74% | 59.2 | 1734 |
| 换 teacher 线：M(.4,.6) ⇐ M(0,1) @0.7 † | 48.0 | 77% | 62.1 | 1433 |
| AR 参考：Qwen2.5-7B-Instruct 贪心（不同解码器） | 55.3 | 78% | 70.9 | 1393 |

† 9/30 B300 旧 run。AR 的写完率按文本含 boxed 计，解码器不同，只作参考。

控制变量怎么读：A(3.0) 已崩（72% 写完、精度 47），门控只能把写完率救回 77%；权重中点 (0.7,1.3) 写完率 89% 但精度 49.8，没有混合的 57.3；
换 student 为 Ins 规律相同（写完率 76→93%，精度 48.5→52.9）；over merge M(0,1) 当 teacher 本来就写不完（74%），所以门控只能提精度、提不了写完率，总分上不去。
AR 的结构完全不同：写完率只有 78%，但写完的题里 70.9% 正确；我们的系统靠写完率追，精度差 13 个点。

两个相反的趋势：
1. **写完率随剂量单调上升**（81 → 95%）：teacher 的 token 让答案在 1024 token 内写到结尾。这是 teacher 带来的。
2. **写完的题里的准确率先升后降**（51.9 → 57.3 → 48.8）：全部用 teacher 内容时，退回 teacher 自己的 49.5；保留 15% student 的 token 时，
   写完的题比两个父模型都更准（57.3 > 51.9, 49.5）。

所以 85% 是两者的乘积最大点：既基本拿到 teacher 的写完率，又没有继承 teacher 在内容上的低精度。
100% 时 teacher 的错误沿它自己的轨迹自我强化（长、啰嗦、2800 字符），少量 student token 打断了这种漂移；
打断的位置不重要（随机也行），所以置信度不携带信息。

含义：这个效应是"两个父模型的互补"（一个会写完、一个更精确）而不是"teacher 更强"；logit 级混合可能比硬换 token 更好地拿到两者。

## AR 参考线被格式低估（2026-10-12，零 GPU，scratchpad/ar_lenient.py）
AR 没有 `\boxed` 的题（后 300 的 66 题 / 全 500 的 111 题）不是截断（中位 1366 字符，结尾是完整结论句），是没按格式写。
用宽松抽取（结尾的 \( \) / $ $ / 最后的数）重打分：**AR 后 300 = 70.7（严格 55.3），全 500 = 71.0（严格 56.0）**；
同样的宽松打分用在我们最好的门控上只从 51.0 到 52.0（我们的未写完是真截断）。
→ 和 AR 的真实差距约 19 个点，不是 4 个点。"超过 AR"在严格打分下成立的话也只是格式假象。
